# 學習歷程群島 v3｜精緻互動版

## 這版升級
- 更細緻的視覺：柔和漸層、互動卡片、浮動星光、晶體、雲朵、島嶼光環與更清楚的操作回饋。
- 點選每座島的房間卡片，可展開進一步反思問題。
- 成就徽章：初次探索、誠實省察、同理之心、謙卑前行、群島旅人。
- 今日小任務：可切換生活實踐任務，完成後有即時回饋。
- 學習選擇會保存在目前裝置的瀏覽器，重新開啟仍可接續；也可重新開始。
- 保留前五站選擇影響第六站「現在的我」的成長輪廓。

## 更新 GitHub Pages
1. 下載 ZIP 並解壓縮。
2. 在 `wtlin0605/learning-archipelago` 根目錄選 `Add file` → `Upload files`。
3. 上傳新版 `index.html`，確認覆蓋後按 `Commit changes`。
4. 等待 GitHub Pages 部署，開啟網站並按 Ctrl+F5 強制重新整理。

3D 場景仍需連線至 jsDelivr CDN。成績與答案目前只保存在學生自己的瀏覽器，不會自動傳到老師端。
