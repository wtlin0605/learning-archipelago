# 學習歷程群島 v2｜互動選擇版

## 新增功能
- 前五段經歷各有情境題與三種回應選項。
- 選擇會累積到第六站「現在的我」的成長輪廓。
- 可以回頭修改答案、查看反思回饋、複製個人成長反思或重新開始。
- 手機、平板與桌面版響應式排版；原有 3D 島嶼導覽保留。

## 更新 GitHub Pages
1. 下載 ZIP 並解壓縮。
2. 到 GitHub 專案 `wtlin0605/learning-archipelago` 根目錄。
3. 點 `Add file` → `Upload files`，上傳新版 `index.html` 覆蓋舊檔。
4. 點 `Commit changes`，等待 Pages 部署完成。
5. 開啟網站並按 Ctrl+F5 強制重新整理。

3D 場景需要連線至 jsDelivr CDN。此版本的選擇在目前瀏覽器頁面互動中即時計算；重新載入後會重新開始。
