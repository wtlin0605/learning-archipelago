# 學習歷程群島 v6｜修復整合版

本版從可運作的 v4 網站重新整合故事遊戲，保留原本六站 3D 群島、島嶼清單、五段選擇影響「現在的我」、成就徽章與今日生活任務，並加入四個故事遊戲：
- 佩佩的氣球：操作膨脹／縮小。
- 阿德的回應：報復、暫停、溫和說真話，顯示不同後果。
- 西門的皇冠：依動機改變皇冠外觀。
- 我的成長角色卡：依遊戲選擇產生角色卡，可下載 SVG。

## 更新
下載 `index.html`，到 GitHub 專案根目錄 `Add file` → `Upload files`，上傳並覆蓋舊檔，按 `Commit changes`。部署後以 Ctrl+F5 強制重新整理。

若要保留目前線上版本，可先在 GitHub 對舊版建立備份或下載原始 `index.html`。
