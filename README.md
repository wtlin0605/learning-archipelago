# 學習歷程群島 v5｜故事遊戲互動版

## 新增內容
1. 佩佩的氣球：點擊按鈕改變氣球大小，搭配反思回饋。
2. 阿德的回應：報復、先停下來、溫和說真話三種選擇，顯示不同的故事後果。
3. 西門的皇冠：選擇想被稱讚、分享功勞、幫助別人並歸榮耀給上帝，皇冠大小與裂痕會改變。
4. 個人成長角色卡：根據互動結果與前五站已完成的選擇，生成角色卡，並可下載 SVG 圖檔。
5. 支援手機與桌面版。

## 更新網站
下載 ZIP 並解壓縮，到 GitHub 專案 `wtlin0605/learning-archipelago` 根目錄點 `Add file` → `Upload files`，上傳新版 `index.html` 並按 `Commit changes`。部署後用 Ctrl+F5 強制重新整理。

注意：本版互動選擇不會自動傳送給教師。
