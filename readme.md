# 學習歷程群島 v8｜氣球大頭症（3D 沉浸探索與海洋生態版）

本專案將《氣球大頭症》品格與生命教育單元轉化為全畫面 3D 互動學習歷程群島，讓學習者直接透過點選 3D 島嶼開啟專屬互動艙，在探索六座島嶼、撰寫房間省思筆記、完成情境抉擇與操作故事實驗室的過程中，練習「在順境中謙卑，在受挫時選擇愛，並把榮耀歸給上帝」（羅馬書 12:3）。

## ✨ v8 全新升級亮點

1. **🏝️ 點擊島嶼開啟「專屬互動探索艙」（無須向下捲動網頁）**
   * 全畫面 3D 群島視角，點選任一島嶼或底部迷你導覽列時，小帆船會自動航行至該島，並從側邊滑出該島專屬的**「島嶼探索互動艙」**。
   * 每座島嶼皆整合三大互動分頁：
     * **📖 故事與房間**：閱讀事件因果、點選 3 間故事房、撰寫自動儲存的本機省思筆記。
     * **🧭 本島抉擇**：在各島直接完成第 1～5 站情境選擇，並於第 6 座島即時繪製 **Canvas 四向度成長雷達圖**。
     * **🧪 互動實驗室**：各島配置專屬互動實驗（第 1 島：佩佩的氣球、第 2 島：阿德的回應模擬器、第 3 島：屬靈軍裝與今日生活小任務、第 4 島：西門的皇冠動機透視鏡、第 5 島：8 枚成長徽章館、第 6 島：3D 炫光成長角色卡工坊與 PNG/SVG 下載）。

2. **📐 島嶼規模與內容豐盛度動態連動**
   * 每座島嶼的 3D 基礎面積與島上建築、花草、水晶數量，皆依該島的「能力數量、故事房間與實驗室內容豐盛度」成正比規範（內容越豐富的島嶼範圍越大，如第 6 座成長總島規模最大）。
   * **動態成長機制**：當學習者在某座島撰寫房間省思筆記、完成該站抉擇或操作實驗室時，該座 3D 島嶼的面積規模會即時動態擴大！

3. **🐋 豐富海洋與天空生態系 (`Three.js` 動態模型)**
   * **🕊️ 展翅飛行的海鷗群**：10 隻海鷗在群島上空盤旋並拍動雙翼。
   * **🐋 噴水換氣的巨型藍鯨**：在群島外圍深水區游動、擺動尾鰭，浮出水面時會噴出白色水柱（支援點擊互動與鏡頭追蹤）。
   * **🐬 躍出水面的海豚群**：成群沿拋物線躍出水面再潛入海中，激起白色水花漣漪。
   * **🛳️ 環島巡航的大型豪華郵輪**：多層甲板、夜晚發光舷窗、雙煙囪與船尾浪花，環繞群島航行（點擊郵輪或下方「🛳️ 追蹤郵輪」可鳴笛並跟隨視角）。
